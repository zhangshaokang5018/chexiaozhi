# 后端服务启动说明（新人必读）

> 适用对象：拉取本仓库后，需要在本机启动 `car-server` 后端服务的开发者。
> 目标：从零到能访问 `http://localhost:5000/api/ping`。

当前后端为**阶段 0 最小基座**，只有一个 `/api/ping` 接口，用于验证小程序与服务端联通。后续阶段会扩展 `/api/chat` 等接口，但启动方式不变。

---

## 1. 环境准备（只需做一次）

| 工具 | 版本要求 | 说明 |
| --- | --- | --- |
| Python | 3.11+（开发用 3.11.x） | 必须 |
| Git | 任意较新版本 | 拉代码用 |

检查 Python 是否安装：

```bash
python --version
```

- 如果显示 `Python 3.11.x` 即可。
- 如果提示找不到命令：去 https://www.python.org/downloads/ 安装，**安装时务必勾选 "Add Python to PATH"**。
- macOS / Linux 上命令可能是 `python3`，下文凡是 `python` 都可替换为 `python3`。

git clone git@github.com:zhangshaokang5018/chexiaozhi.git
cd chexiaozhi

如果已经 clone 过，只需更新：

git pull

## 3. 创建虚拟环境并安装依赖（只需做一次）

> 虚拟环境（`.venv`）是每个人在自己电脑上独立创建的，**不会**提交到 Git（已在 `.gitignore` 忽略）。所以新人拉到代码后必须自己创建一次。

进入后端目录：

```bash
cd car-server
```

### Windows（PowerShell 或 CMD）

```bat
python -m venv .venv
.venv\Scripts\python -m pip install --upgrade pip
.venv\Scripts\python -m pip install -r requirements.txt
```

### Windows（Git Bash）

```bash
python -m venv .venv
./.venv/Scripts/python -m pip install --upgrade pip
./.venv/Scripts/python -m pip install -r requirements.txt
```

### macOS / Linux

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install --upgrade pip
./.venv/bin/python -m pip install -r requirements.txt
```

安装成功后，可确认 Flask 已装上：

```bash
# Windows
.venv\Scripts\python -m pip list | findstr -i flask
# macOS / Linux
./.venv/bin/python -m pip list | grep -i flask
```

预期能看到 `Flask` 和 `flask-cors`。

---

## 4. 启动服务

在 `car-server` 目录下：

### Windows

```bat
.venv\Scripts\python app.py
```

### macOS / Linux

```bash
./.venv/bin/python app.py
```

> 也可以先「激活」虚拟环境再直接用 `python app.py`：
> - Windows PowerShell：`.venv\Scripts\Activate.ps1`
> - Windows CMD：`.venv\Scripts\activate.bat`
> - Git Bash / macOS / Linux：`source .venv/Scripts/activate`（Win）或 `source .venv/bin/activate`（Mac/Linux）
> 激活后命令行前面会出现 `(.venv)`，此时运行 `python app.py` 即可。

启动成功后终端会打印类似：

```text
 * Running on http://127.0.0.1:5000
 * Running on http://192.168.x.x:5000
Press CTRL+C to quit
```

**保持这个终端窗口开着**，服务就一直在运行。按 `Ctrl + C` 可停止。

## 5. 验证启动成功

新开一个终端，或用浏览器访问：

```bash
curl http://localhost:5000/api/ping
```

预期返回：

```json
{
  "ok": true,
  "name": "chexiaozhi-server",
  "version": "0.1.0"
}
```

看到这个 JSON 就说明后端启动成功了 ✅。

服务端运行的终端里也会打印一行访问日志：

```text
127.0.0.1 - - [.....] "GET /api/ping HTTP/1.1" 200 -
```

## 6. 小程序连接后端

小程序默认请求 `http://localhost:5000`（见 `car-miniapp/miniprogram/utils/request.ts` 的 `BASE_URL`）。

- **本机用微信开发者工具调试**：保持 `localhost:5000`，并在「详情 → 本地设置」勾选「不校验合法域名…」。
- **手机真机预览**：把 `BASE_URL` 里的 `localhost` 换成电脑的局域网 IP（启动日志里 `192.168.x.x` 那一行），手机和电脑连同一个 WiFi。

---

## 7. 常见问题排查

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `python: command not found` | 没装 Python 或没加入 PATH | 重装 Python 勾选 Add to PATH；或改用 `python3` |
| `No module named flask` | 没装依赖，或没用 `.venv` 里的 python | 回到第 3 步装依赖；启动时确认用的是 `.venv\Scripts\python` |
| `Address already in use` / 端口被占用 | 5000 端口被其他程序占用 | 改 `app.py` 末尾 `port=5000` 为其他端口（如 5001），并同步改小程序 `BASE_URL` |
| 小程序请求失败 / 网络错误 | 服务没启动 / 没勾选「不校验合法域名」 | 确认终端里服务在跑；勾选开发者工具本地设置 |
| 真机连不上 | 用了 `localhost` | 真机要用电脑局域网 IP，且同一 WiFi |
| 拉代码后报错找不到 `.venv` | 虚拟环境不入库，需各自创建 | 重新执行第 3 步 |

## 8. 多人协作约定

- `.venv/`、`__pycache__/`、`.env` 等**不提交**到 Git（已在 `car-server/.gitignore` 忽略），每个人在本机各自创建。
- `requirements.txt` 是依赖清单：**新增依赖时，安装后要更新它并提交**，方便其他人 `pip install -r requirements.txt` 同步。
  ```bash
  # 安装新依赖后导出（在已激活的 .venv 中）
  pip freeze > requirements.txt   # 或手动添加具体包名+版本
  ```
- 拉到别人新提交的代码后，如果 `requirements.txt` 有变化，记得重新执行一次：
  ```bash
  .venv\Scripts\python -m pip install -r requirements.txt
  ```
